# Bus-system

This is a collaborative project completed for a first-semester Programming Fundamentals course. The goal was to create a simple bus reservation system that allows users to book, modify, and cancel seat reservations using HTML, CSS, and plain JavaScript.

## Features

-   **Seat Reservation**: Book one or more seats by providing a name and selecting specific seat numbers.
-   **Reservation Modification**: Update the details of an existing reservation.
-   **Reservation Cancellation**: Free up previously booked seats.
-   **Visual Seat Chart**: A table provides a visual representation of all 40 bus seats, indicating which are occupied and by whom.
-   **Input Validation**: The system checks to ensure seat numbers are within the valid range (1-40) and prevents booking of seats that are already taken.

## Technologies Used

-   HTML
-   CSS
-   JavaScript

## Getting Started

1.  Clone the repository to your local machine:
    ```bash
    git clone https://github.com/nery17pg/bus-system.git
    ```
2.  Navigate into the cloned directory.
3.  Open the `proyectoborrador.html` file in any modern web browser.

## How to Use

### To Reserve Seats
1.  Enter your name in the **Nombre del cliente** field.
2.  Enter the total number of seats you wish to book in the **Total de asientos** field.
3.  Click the **Registrar** button.
4.  In the pop-up prompts that appear, enter each desired seat number one by one. The table will update to show your reservation.

### To Modify a Reservation
1.  Enter the relevant details in the input fields.
2.  Click the **Modificar** button.
3.  Enter the seat numbers you wish to update in the subsequent pop-up prompts.

### To Cancel a Reservation
1.  Enter the number of seats you want to cancel in the **Cantidad de asientos a eliminar** field.
2.  Click the **Eliminar** button.
3.  Enter each seat number you wish to cancel in the pop-up prompts. The seats will be cleared from the table.
